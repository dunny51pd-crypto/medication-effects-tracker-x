# Medication Effects Tracker XP

A simple four-week personal tracker for medication check-ins.

## Deploy
Upload the contents of this folder to a GitHub repository and deploy that repository with Netlify.

## iPhone
Open the deployed site in Safari, use Share → Add to Home Screen.

## Data
The prototype stores entries locally in the browser. Use Export CSV regularly if the data matters to you.

This is a personal tracking tool, not a medical decision tool.
